# Personal Data Safety Checker

## Description
Personal Data Safety Checker is a cybersecurity-based web project that helps users identify whether their personal information is secure or exposed online.

The system checks:
- Password strength
- Unsafe links
- Privacy risks
- Data safety

It helps users improve digital privacy and cybersecurity awareness.

Backend functionality is handled using Node.js and Express.js.

---

## Features
- Password strength checker
- Email safety analysis
- Security recommendations
- User-friendly interface
- Privacy protection tips

- Node.js
